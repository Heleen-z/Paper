# 研究方向与实施指南

目标是让智能体在有限预算下发现值得询问的目标域样本，并把人工修订可靠地传入模型训练。当前采用 Office-Home Product → Real-World 单方向，正式决策以[行动指南](../毕业论文行动指南.md)为准。

| 顺序 | 核心工作 | 检查方式 |
|---|---|---|
| 数据 | 原图对齐、近重复分组、约 70/30 目标划分 | 按 ID 取回同一图的两套 65 类分数 |
| 算法 | 四组选样器，双通道为主策略；两项零人工参照 | 按相同机会或实际标签预算分别作图，重算错例、重叠率及配对准确率 |
| 复现 | LADA 拆跑 LAS＋微调和 LAS＋LAA | 将作者协议与本地封存评估分表 |
| 执行 | 预算变更、跳过、修订、冻结快照、暂停恢复 | 追踪真实反馈至新模型及下一轮选择 |
| 写作 | 将实际记录映射到方法、结果与局限 | 仅将已采集的结果填入[工作稿](初步研究与撰写/论文前三章初稿.md) |

模型超参数、抽样和统计约定见[执行方案](../research/experiments/模型实验执行方案.md)。语言指令测试见[评测手册](../research/experiments/智能体任务评测.md)。真人标注效率和其他迁移方向按工期扩展。
