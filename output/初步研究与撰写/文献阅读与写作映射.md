## 第二批前沿与扩展

2025—2026年的视觉语言主动学习、CLIP适配和主动域适应工作用于更新研究背景。它们的任务、监督资源及代码完备程度存在差异，不以发表年份直接决定主线复现选择。下列记录保留原核验状态，正式提交前再检查最新版本。

- R05 Learning to Prompt for Vision-Language Models（2022，正式期刊论文；预印本首次发布于2021年）。学习提示向量与手写提示、对话记忆不同；目标少样本适配不等同于有源域监督的ADA。 [来源](https://arxiv.org/abs/2109.01134)
- R06 Tip-Adapter: Training-free Adaption of CLIP for Few-shot Classification（2022，正式会议论文）。适用于少样本分类，不应把缓存更新直接称作已复现的LADA。 [来源](https://arxiv.org/abs/2207.09519)
- R08 Diffusion-Based Probabilistic Uncertainty Estimation for Active Domain Adaptation（2023，正式会议论文）。增加模型训练与多次采样开销，非本科主线首选。 [来源](https://proceedings.neurips.cc/paper_files/paper/2023/hash/374050dc3f211267bd6bf0ea24eae184-Abstract-Conference.html)
- R09 Category-Aware Active Domain Adaptation（2024，正式会议论文）。原协议含逐类二分类代理与每类准确率，不应直接对比常规65类top-1表格。 [来源](https://proceedings.mlr.press/v235/xiao24b.html)
- R10 D3GU: Multi-Target Active Domain Adaptation via Enhancing Domain Alignment（2024，正式会议论文）。多目标协议不同于单源到单目标；不建议作为本课题最小实现。D3是此文域判别模块，不是已核实的独立2023同名ADA方法。 [来源](https://arxiv.org/abs/2401.05465)
- R11 Active Learning for Vision Language Models（2025，正式会议论文；预印本首次发布于2024年）。VLM主动学习，不自动等同于有标注源域到目标域的ADA。不能宣称不确定性+多样性+CLIP组合为首创。 [来源](https://openaccess.thecvf.com/content/WACV2025/html/Safaei_Active_Learning_for_Vision_Language_Models_WACV_2025_paper.html)
- R12 Certainty and Uncertainty Guided Active Domain Adaptation（2025，作者arXiv页面明确注明已被ICIP 2025接收）。本次未核实可用官方代码，不承诺作为必做复现；伪标签必须与人工真标签分开计数。 [来源](https://arxiv.org/abs/2505.19421)
- R13 CLIP-guided sample selection for active domain adaptation（2026，正式期刊论文，卷期日期2026-02-28；DOI含2025并不等于卷期年份2025）。本次仅核验出版页摘要，未获得可核实官方代码或全面复现信息；不引用其SOTA宣称作为本课题预期结果。 [来源](https://doi.org/10.1016/j.knosys.2025.115165)
- R14 Explicit Uncertainty Modeling for Active CLIP Adaptation with Dual Prompt Tuning（2026，预印本；所查页面未注明正式接收）。是主动CLIP适配方案；不能将其当成已验证的通用域适应或人机交互结论。 [来源](https://arxiv.org/abs/2602.04340)
- R15 Conformal Cross-Modal Active Learning（2026，预印本；所查页面未注明正式接收）。校准数据也消耗监督资源；分歧与多模态选样不是尚无人研究的方向。 [来源](https://arxiv.org/abs/2603.23159)
- R16 Uncertainty and diversity based selection for active learning in vision-language models（2026，正式期刊论文，卷期日期2026-09）。官方七数据集协议属于VLM主动学习，未直接提供Office-Home源目标ADA配置；移植后需如实命名且重新公平评测。 [来源](https://doi.org/10.1016/j.inffus.2026.104260)
- R18 Tent: Fully Test-Time Adaptation by Entropy Minimization（2021，正式会议论文；预印本首次发布于2020年）。没有主动查询人工标签，不能用来替代ADA的查询与反馈闭环。 [来源](https://arxiv.org/abs/2006.10726)
- R20 Active Learning for Domain Adaptation: An Energy-Based Approach（2022，正式会议论文）。其完整方法含适配目标，不应仅比较选样器却把全部收益归因于采样。 [来源](https://ojs.aaai.org/index.php/AAAI/article/view/20850)
