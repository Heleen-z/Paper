# 模型实验执行方案

首个正式方向为 Office-Home Product → Real-World。本方案落实[行动指南](../../毕业论文行动指南.md)，以固定标签额度下的高置信度错例发现率和独立测试表现评价选样。

## 数据与查询

从原图建立匿名 ID、内容哈希、近重复组、类别与划分清单。按组隔离已确认的近重复图，按类分层划分目标域为约 70% 查询池和 30% 测试集。源域留独立验证集。登记各类计数、划分种子 2026 和清单哈希。查询工具只获取候选图像与预测，不获取真值或含类名路径。对齐视觉模型与冻结 CLIP RN50 的 65 类分数、模板、校准方式和类别顺序。

## 正式运行矩阵

| 运行 | 具体设置 |
|---|---|
| 零标签起点 | 仅源域监督的视觉模型，在同一目标测试集评估。 |
| 四组选择器 | 随机；纯视觉熵；旧规则消融（分歧优先、组内按熵）；主策略（双通道）。 |
| 双通道定额 | 本轮额度 b，先取 ⌊b/2⌋ 张第一候选不同且双方最大类概率乘积最高的图片，余量按剩余样本视觉熵降序补齐。冲突不足时用熵通道补齐。同分按匿名 ID 排序。 |
| 两项零人工参照 | 冻结 CLIP 直接分类；以相同查询机会、双通道和 CLIP 硬伪标签训练视觉模型。分别记查询次数、付费或模拟人工标签数和伪标签数。 |
| 文献复现 | 首选 LADA，拆跑 LAS＋普通微调和 LAS＋LAA。核对作者协议与本地划分、训练可见数据和预算，分表呈现。备选 EvidentialADA，披露证据头及伪标签开关。 |

累计预算为 ⌊rN/100⌋，N 为初始查询池大小，r 从 1 到 5。锁定种子 11、23、37。各轮选择依赖上一轮评分，训练从固定的同种子源域权重重新开始。用锁定的累计目标标签快照和源域批次分别计算平均损失，两项等权；四个选择器共用训练步数、优化器与批量设置。目标标签在查询后揭示。实际训练前登记参数、设备和软件版本。

## 每轮交付

1. 记录候选池、入选 ID、排序通道、视觉置信度和熵、CLIP 候选及版本。在揭示真值前保存分数，揭示后保存反馈来源、预算交易与快照。
2. 保存源初始检查点、用于查询的前轮模型、本轮训练配置、新检查点与逐图测试预测。按[运行记录模板](../../output/初步研究与撰写/模型实验记录模板.csv)归档。
3. 报告预算—Top-1 曲线、宏平均类别召回、三种子配对差值。第 5 轮、种子 11 对双通道与纯熵进行配对 McNemar 检验，列出两边独对的计数。其余种子报告波动。
4. 以最大概率 ≥0.80、≥0.90、池内低熵半区三种口径列每百次查询发现的视觉错例数。报告与同种子同轮纯熵队列的交集占当轮额度比例、类别覆盖与分布熵。分歧样本按视觉独对、图文独对、双方皆错拆分，一致样本另列。
5. 从保存的预测重算至少一轮准确率，从查询并集核对预算。从标签快照重建一轮训练，确认标签修订生效。旧特征试跑使用不同划分且只有随机与熵，单独归档。
