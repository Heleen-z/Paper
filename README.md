## 目录

- `output/`：可阅读、编辑或提交的报告、PPT、初稿与研究材料。
- `research/`：研究协议、文献索引和开题内容。
- `assets/`：图示及来源说明。

研究先用 Office-Home 商品图到真实照片的迁移任务检验双通道选样，并以原分歧规则作消融，并追踪用户反馈怎样进入下一轮模型更新。当前实施范围以行动指南为准。

开题报告、PPT、学校提交版、三种架构选型材料、早期文献建议和带日期的压缩包记录当时的立项方案。当前实验使用上方行动指南、研究协议和实验设计索引。特征级试跑脚本只支持旧划分的随机与熵，正式原图实验仍待实施。

文献及第三方图片的来源见对应文档与[图片来源说明](assets/SOURCES.md)。历史压缩包反映制作时的材料快照，最新内容以展开的文件为准。
